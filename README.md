A deterministic momentum-rotation paper-trading bot for hourly Solana bars: it holds the top 4 symbols whose EMA(8)/EMA(24) trend and 24h momentum agree (moderate trends only when market breadth is up), exits on trend break, a -5% stop or a 4% trailing stop, and otherwise sits in USDC — aiming to beat buy-and-hold in both directions of a 3-day window.

## Run it

```sh
node main.ts
```
